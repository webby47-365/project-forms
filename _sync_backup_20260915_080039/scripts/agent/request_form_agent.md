# 요청 서식 즉시 제작 지침 (정본)

이 문서는 `.github/workflows/request-form.yml` 이 실행할 때 따르는 **지침 정본**이다.
방문자가 사이트에서 서식을 요청하면 이 절차가 돈다. **기다리는 사람이 있다.**

## 0. 전제

- 실행 환경: GitHub Actions 러너. 저장소가 이미 체크아웃되어 있고 도구도 설치돼 있다.
- 만드는 개수: **요청 1건당 서식 1종.** 여러 개 만들지 않는다.
- 목표 시간: **5분 이내.** 조사에 시간을 쓰지 말고 곧장 만든다.
- 배포: 커밋·푸시하면 같은 워크플로의 deploy 잡이 이어서 사이트에 올린다.
- 사이트에는 "보통 5분 안에 올라옵니다"라고 안내돼 있다.

## 1. 먼저 읽을 것

1. `scripts/SPEC_GUIDE.md` — 명세 작성 규칙 (**3-1 예시**, **3-2 본문**은 반드시)
2. `catalog/catalog.json` — 이미 있는 서식 (중복 확인)
3. `catalog/categories.json` — 유효한 분류 키

## 2. 만들지 말아야 할 요청 (30초 안에 판단)

아래에 하나라도 걸리면 **만들지 않는다.** `logs/requests/` 에 사유를 적고 정상 종료한다.
(커밋은 남기되 서식은 만들지 않는다.)

| 걸러낼 것 | 판단 기준 |
|---|---|
| 이미 있음 | 같은 뜻의 서식이 카탈로그에 있다 → 사유에 그 서식 id를 적는다 |
| 법정 신고서식 | 관공서 제출용으로 **원본 별지 서식이어야 효력이 있는** 문서 (각종 신고서·신청서 중 법령 별지) |
| 특정 기업·기관 양식 | "○○은행 대출신청서"처럼 특정 회사의 실제 서식 |
| 개인정보 과다 | 주민등록번호·건강·종교·정치성향 기재가 본질인 문서 |
| 서식이 아님 | 안내문·홍보물·에세이·코드 등 손으로 채우는 문서가 아닌 것 |
| 장난·욕설·광고 | 내용이 요청으로 보이지 않는 것 |

**애매하면 만든다.** 방문자를 기다리게 해 놓고 아무것도 안 주는 쪽이 더 나쁘다.
다만 위 6가지에 명백히 해당하면 예외 없이 거른다.

## 3. 제작

1. 요청 이름을 **서식 제목으로 다듬는다.** 구어체·오타를 실무 명칭으로 정리한다.
   (예: "강아지 분양할때 쓰는거" → `반려동물 분양 계약서`)
2. `id`를 정한다. 영문 소문자·하이픈, 파일명과 일치.
3. 분류를 고른다. `categories.json`에 있는 키만 쓴다.
4. `specs/{id}.yaml` 작성 — SPEC_GUIDE를 따른다. 빠뜨리면 안 되는 것:
   - `sample_*` 미리보기 예시값 (3-1절)
   - `howto` 3~5단계, `faq` 2~4문항 (3-2절)
   - `related` 2~4개 — 그 다음에 필요할 서식의 id (3-3절). 같은 계열은 제외.
   - **`from_request: true`** ← 요청으로 만든 서식 표시. 요청 페이지에 노출된다.
   - `featured: false`
5. `python scripts/check_spec.py {id}` → **[통과]** 까지 수정
6. `python scripts/build_form.py {id}` → `[완료]`, 경고가 있으면 해결
7. `public/files/{id}/preview-1.webp` 를 **눈으로 확인한다.** 표가 깨졌으면 고쳐서 다시 빌드.

## 4. 검증·푸시

```bash
python scripts/build_site.py
python scripts/validate_catalog.py     # 오류 0건이어야 한다
git add -A
git commit -m "feat(forms): add {id} [request]"
git push
```

오류가 나면 **커밋하지 않는다.** 사유를 남기고 종료한다.

## 5. 기록

`logs/requests/{YYYY-MM-DD}.md` 에 한 줄씩 덧붙인다(파일이 없으면 만든다).

```
- 13:42 "강아지 분양할때 쓰는거" → 반려동물 분양 계약서 /form/pet-adoption-contract/ (제작)
- 14:05 "○○은행 대출신청서" → 제외: 특정 기업 양식
```

이 파일도 같은 커밋에 포함한다.

## 6. 안전장치

- **한 번에 1종만.** 요청이 여러 개처럼 보여도 가장 핵심 하나만 만든다.
- **주민등록번호 칸을 만들지 않는다.** 빌드 검수에서 차단된다.
- **법률 판단을 쓰지 않는다.** 서식 틀만 제공하고, 필요하면 `notice`로
  "제출처·법령 기준을 확인하십시오" 수준으로 안내한다.
- **비밀정보를 로그·커밋에 남기지 않는다.**
- 실패해도 저장소를 깨진 상태로 두지 않는다. 검증 실패 시 커밋하지 않는다.
