# 서식 요청 접수 설치 안내 (관리자용, 1회)

방문자가 사이트에서 서식을 요청하면 **보통 5분 안에** 만들어 올리는 기능이다.
아래 6단계를 한 번만 해두면 이후에는 손댈 일이 없다. 소요 약 15분.

```
방문자 요청 → 구글 시트 기록 → GitHub에 신호 → 서식 1종 제작 → 배포 (5~7분)
             └ 상한 초과분은 시트에 대기 → 다음 날 08:00 작업이 우선 처리
```

**받는 항목은 서식 이름과 용도 두 가지뿐이다.** 이름·연락처·이메일을 받지 않으므로
개인정보처리방침을 고칠 필요가 없다. 항목을 늘리려면 처리방침부터 검토해야 한다.

---

## 1단계 — 구글 시트 만들기

구글 드라이브에서 **새 스프레드시트**를 만든다. 이름은 `무료서식 요청함` 정도면 된다.
시트 안은 비워 두어도 된다. 필요한 표는 스크립트가 알아서 만든다.

## 2단계 — Apps Script 붙여넣기

그 스프레드시트에서 **확장 프로그램 → Apps Script** 를 연다.
편집기에 있는 기본 코드를 **전부 지우고**, 저장소의
`scripts/agent/apps_script.gs` 내용을 **통째로 붙여넣은 뒤 저장**(Ctrl+S)한다.

## 3단계 — GitHub 토큰 발급 (무료)

구글에서 GitHub로 신호를 보내려면 열쇠가 하나 필요하다. 결제와는 무관하다.

1. GitHub → 우상단 프로필 → **Settings**
2. 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens**
3. **Generate new token**
   - Token name: `freeforms-request`
   - Expiration: 1년 (만료되면 다시 발급해 4단계 값만 교체한다)
   - Repository access: **Only select repositories** → `project-forms`
   - Permissions → Repository permissions → **Contents: Read and write**
4. **Generate token** → 나온 값을 복사한다

⚠️ 이 값은 **한 번만** 보인다. 복사해서 바로 4단계로 간다. 채팅·메모·검색창에 붙여넣지 않는다.

## 4단계 — 스크립트 속성 두 개 넣기

Apps Script 편집기 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **스크립트 속성** →
**속성 추가** 로 두 개를 넣는다.

| 속성 | 값 |
|---|---|
| `GITHUB_REPO` | `webby47-365/project-forms` |
| `GITHUB_TOKEN` | 3단계에서 복사한 토큰 |

저장한다.

## 5단계 — 웹 앱으로 배포

Apps Script 편집기 우상단 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택

- 설명: `서식 요청 접수`
- 실행 계정: **나**
- 액세스 권한: **모든 사용자**  ← 방문자가 로그인 없이 보낼 수 있어야 한다

**배포**를 누르면 권한 승인 창이 뜬다. 승인하면 **웹 앱 URL** 이 나온다.
`https://script.google.com/macros/s/.../exec` 형태다. 이 주소를 복사한다.

> 승인 과정에서 "이 앱은 확인되지 않았습니다" 경고가 나오면
> **고급 → (프로젝트 이름)(으)로 이동** 을 눌러 계속 진행한다. 본인이 만든 스크립트다.

## 6단계 — 사이트에 주소 넣고 배포

로컬 `C:\Project_Forms\catalog\requests.json` 을 메모장으로 열어 두 줄을 고친다.

```json
  "enabled": true,
  "endpoint": "5단계에서 복사한 주소",
```

저장한 뒤 PowerShell에서:

```powershell
cd C:\Project_Forms
.\deploy_forms.ps1 -SkipBuild
```

배포가 끝나면 `https://freeforms.kr/request/` 에 입력 폼이 나타난다.

---

## 시험해 보기

1. `https://freeforms.kr/request/` 에서 없는 서식을 하나 요청한다
   (예: `반려동물 분양 계약서`)
2. "지금 만들고 있습니다" 안내가 나오면 접수 성공
3. GitHub → Actions → **요청 서식 즉시 제작** 이 돌기 시작한다
4. 5~7분 뒤 사이트에 서식이 올라온다
5. 구글 시트에도 한 줄이 기록돼 있다

**신호가 안 갈 때**는 Apps Script 편집기에서 함수 `testDispatch` 를 직접 실행해 본다.
실행 기록에 `true` 가 찍히면 토큰·저장소 설정이 맞는 것이다.

## 상한과 남용 방지

| 장치 | 값 |
|---|---|
| 즉시 제작 상한 | 시간당 3건 · 하루 10건 (초과분은 다음 날 아침 처리) |
| 중복 요청 | 24시간 안에 같은 이름이면 한 건으로 합침 |
| 이미 있는 서식 | 제작하지 않고 "바로 받으러 가기" 링크를 보여줌 |
| 봇 | 사람에게 안 보이는 숨김 칸으로 자동 제출 차단 |
| 글자 수 | 서식 이름 40자 · 용도 120자 |

상한을 바꾸려면 `apps_script.gs` 위쪽의 `LIMIT_PER_HOUR`, `LIMIT_PER_DAY` 를 고치고
Apps Script에서 **다시 배포**한다(배포 → 배포 관리 → 편집 → 새 버전).

## 접수를 잠시 멈추려면

`catalog/requests.json` 의 `"enabled"` 를 `false` 로 바꾸고 배포하면 폼이 사라진다.
구글 쪽은 건드릴 필요 없다.

## 요청이 걸러지는 경우

에이전트가 아래에 해당하는 요청은 만들지 않는다 (`scripts/agent/request_form_agent.md` 2절).
걸러진 사유는 `logs/requests/{날짜}.md` 에 남는다.

- 이미 있는 서식
- 관공서 제출용 법정 신고서식 (원본이어야 효력이 있음)
- 특정 기업·기관의 실제 양식 (저작권)
- 주민등록번호·건강 등 민감정보 기재가 본질인 문서
- 서식이 아닌 것 (안내문·홍보물 등)
- 장난·욕설·광고
