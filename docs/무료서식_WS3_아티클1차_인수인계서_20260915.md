## 5. 개발가이드 반영 필요 항목
1. 자동 생산 콘텐츠는 **draft 상태를 명세에 두고 검사기는 통과시키되 빌드에서 제외**한다 — 에이전트는 계속 일하고 공개는 사람이 통제.
2. 카드·추천 노출은 **명시 지정(show_on) 우선 → 자동 연결 보충** 2단 구조로 두면 편집 의도와 자동화가 충돌하지 않는다.
3. YMYL 글은 기준일·기관 출처를 검사기 필수 항목으로. 기관 원문을 확인 못 한 수치는 넣지 않는다(민간 요약 금지).
4. 작업 폴더=저장소 + `git add -A` 배포 구조에서 병렬 세션을 돌리면 **다른 세션 커밋에 파일이 섞인다** → 세션별 경로 한정 커밋(`git add <paths>`) 또는 동시 배포 금지 규칙 필요.
5. UI 배치는 목업 비교 후 **실제 빌드본으로 한 번 더 캡처**해 좌표를 확인한다(C안 모바일 상세 3,5xx~3,9xxpx, 계산기 2,2xxpx).
