## 4. 개발가이드 반영 필요 항목

1. 날짜가 바뀌는 운영 기준(시즌·명절)은 지시문에 적지 않고 데이터 파일 1곳 + 계산 스크립트로 둔다. 문서와 데이터가 어긋나지 않는다.
2. 측정 이벤트는 템플릿 속성 대신 URL 경로로 판정하면 UI 배치 변경에 코드 수정이 필요 없다.
3. 외부 지표 수집은 파이프라인의 선택 단계로 — 자격증명이 없거나 API 실패해도 종료코드 0, 사유 한 줄. 본 작업(서식 배포)을 막지 않는다.
4. GA4 이벤트 파라미터는 맞춤 측정기준 등록 전에는 Data API에서 안 보인다 → 기본 차원(pagePath·eventName)으로 집계되게 설계.
5. 서비스 계정 키는 로컬 시험 시 환경변수로만 주입하고 finally 에서 제거, 시험 스크립트는 gitignore 패턴 이름으로 만든다(공개 저장소 = 작업 폴더인 구조).
