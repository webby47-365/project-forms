## 1. 디자인 요소 — 여백·깨짐·비대칭

### A-1. [모바일] 헤더 좌우 여백이 0px — 로고와 검색창이 화면 가장자리에 붙음
- 증상: 375px에서 로고 "무료서식 다운로드"의 left = 0px, 헤더 검색창 left/right = 0px. 헤더 컨테이너 padding-left/right = 0.
- 캡처에서 "무료서식"의 '무' 글자가 화면 왼쪽 끝에 밀착. 574px(태블릿 세로)에서도 동일.
- 원인 추정: 헤더 `.wrap` 의 모바일 미디어쿼리에서 좌우 padding이 빠짐(본문 섹션은 16px 여백 정상).
- 수정: 헤더·검색창 컨테이너에 `padding: 0 16px` (본문과 동일 gutter).

### B-3. [공통] 한글 단어 중간 줄바꿈 (word-break 미지정)
- 증상: 모바일 히어로 "양식을 미리 확\n인하고", 카드명 "업무용 차량 사용 신\n청서", "이력서 (아르바이트\n용)", 모음 설명 "필요합\n니다" 등. 카드명·h1·p 모두 `word-break: normal`, `keep-all` 적용 요소 0개.
- 수정: `body { word-break: keep-all; overflow-wrap: anywhere; }` 한 줄. (긴 영문 URL은 anywhere가 처리)

### C-1. [모바일] 티커(최근 업데이트) 라벨과 흐르는 글자가 겹침
- 라벨 오른쪽 끝 93px, 트랙 시작 102px로 간격 9px뿐이라 흐르는 항목 앞글자가 라벨 바로 옆에서 잘려 보임("| ㅏ 관리이력서").
- 수정: 라벨 오른쪽 padding + 트랙에 `mask-image` 페이드, 또는 모바일에서는 티커를 숨김(헤더가 이미 2줄).

### C-2. [모바일] 고정 헤더가 세로 100px(로고줄 + 검색줄) — 812px 화면의 12% 차지
- 항상 sticky라 콘텐츠 가시 영역이 줄어듦. 검색줄은 스크롤 내릴 때 접히고 올릴 때 펼치는 방식 권장.

### C-3. [PC] 푸터 "직장인 도구 · 도장·서명 만들기 · 실수령액 계산기…" — 항목 구분자와 이름 안의 가운뎃점이 같은 기호
- "도장·서명"의 · 와 항목 구분 · 가 같아 어디서 끊기는지 헷갈림. 구분자를 `|` 또는 넉넉한 간격으로.

### 정상 판정(참고)
- 카드 그리드: 같은 줄 카드 높이 전부 408px로 동일(제목 2줄일 때도 버튼 정렬 유지).
- 컨테이너 좌우 대칭: 메인 86/85px, 분류 105/105px, 상세 86/85px.
- 가로 넘침: 전 페이지 scrollWidth = clientWidth (티커 트랙은 의도된 넘침).

## 2. 버튼·기능 무작위 조작 — 사용자가 오류로 느낄 부분

### A-2. [모바일] 햄버거 메뉴를 열면 아래쪽 항목(의료·복지, 직장인 도구 4개)에 도달할 수 없음 ★가장 중요
- 증상: 메뉴 패널 높이 970px > 화면 812px. 패널이 `position: static`으로 sticky 헤더 안에 들어가고 `overflow: visible`이라 **스크롤해도 패널 자체가 안 움직이고 뒤의 본문만 스크롤**됨(scrollY 3588까지 내려도 마지막 항목 top = 1035px로 화면 밖).
- 결과: 폰에서 메뉴로는 "의료·복지" 분류와 계산기·도장 도구 4개를 절대 열 수 없음.
- 수정안: 메뉴 패널을 `position: fixed; top: 헤더높이; bottom: 0; overflow-y: auto` + 열려 있는 동안 `body { overflow: hidden }`.

### B-6. [모바일] 메뉴 패널이 왼쪽 절반(160px)만 흰 박스, 오른쪽은 남색 빈 공간
- PC 드롭다운(submenu) 스타일이 그대로 적용된 모습. 닫기(X) 버튼 없음, 버튼 aria-label이 열린 뒤에도 "메뉴 열기", `aria-expanded` 없음.
- 수정안: 모바일에서 submenu를 폭 100% 리스트(또는 2열 그리드)로, 토글 아이콘 ☰ ↔ ✕ 전환.

### B-2. [PC·모바일] 검색창 돋보기 아이콘을 눌러도 아무 일도 안 일어남
- 헤더 검색(#q)·히어로 검색(#q2) 모두 `<form>` 없이 Enter 키 이벤트로만 동작. 돋보기는 장식 SVG.
- 일반 사용자는 아이콘을 누르고 기다리다 "고장났다"고 느낌. 특히 모바일 키보드에서 Enter 대신 '완료'를 누르는 경우.
- 수정안: 돋보기를 `<button type="submit">`으로, 두 검색창을 `<form action="/search/" method="get">`로 감싸기(JS 없이도 동작 → 접근성·SEO 덤). `enterkeyhint="search"` 추가.

### B-5. [공통] `/favicon.ico` 404
- `<link rel="icon" href="/favicon.svg">`만 있고 .ico 없음. 구형 브라우저·네이버/구글 검색결과 파비콘·북마크에서 기본 아이콘 노출. `apple-touch-icon`·`manifest.json`도 없어 폰 "홈 화면에 추가" 시 빈 아이콘.
- 수정안: favicon.ico(32px) + apple-touch-icon.png(180px) 추가, 콘솔 404 제거.

### C-4. [계산기] 잘못된 입력에 안내가 없음
- 연봉 칸에 "abc" → 조용히 0원, "-5000" → "-5,000"이 그대로 남고 결과 전부 0원. 오류 문구·빨간 테두리 없음.
- 수정안: 음수·문자 입력 시 칸 아래 "숫자만 입력하세요" 한 줄, 값은 0으로 되돌림.

### C-5. [계산기] "결과 이미지 저장" 눌렀을 때 피드백 없음
- "계산 결과 복사"는 버튼 글자가 "복사했습니다"로 0.5초 바뀌어 좋음. 이미지 저장은 버튼 글자 변화 없이 파일만 내려가 폰에서는 저장됐는지 알기 어려움. 같은 방식으로 "저장했습니다" 표시 권장.

### C-6. [도장 위젯] 이름 8자 제한에 안내 없음
- 9자 입력 시 8자에서 조용히 멈춤. 3줄로 작게 새겨져 읽기 어려움. "최대 8자" 힌트 + 5자 이상이면 "서명형을 권장" 안내.

### C-7. [검색] 오타 1글자면 0건 (기존 식별 이슈 재확인)
- "이렬서" → 0건. 정상 케이스는 양호: "근로 계약서" 5종, "이력서 신입" 1종, "resume" 7종, "퇴직" 5종, 빈 검색어는 안내 문구.

### 정상 확인
- 다운로드 링크: PDF `application/pdf`, DOCX 정식 MIME, HWPX는 `application/octet-stream`(다운로드 강제되므로 문제 없음). `download` 속성으로 한글 파일명 저장.
- 서식 요청 폼: 빈 값 제출 시 브라우저 필수값 검증 + 첫 칸 포커스. 접수 문구 3종(신규/중복/이월)·실패 문구 준비돼 있음. 새로고침 시 입력값 자동 비움(중복 전송 방지) 좋음.
- 404: 사이트 헤더·푸터 유지, 제목 "페이지를 찾을 수 없습니다".
- 콘솔 오류: favicon.ico 404 1건 외 없음.

## 3. 완성도·편의성 개선사항

### A-3. [PC 노트북 1366×768] 분류 페이지 왼쪽 사이드바 하단이 잘림
- 사이드바 높이 817px, `position: sticky; top: 78px`, overflow 없음 → 768px 화면에서 하단 "교육 · 학교·학원", "의료·복지" 링크가 스크롤 내내 화면 밖(bottom 880px). 노트북 사용자 대부분(1366×768, 1536×864 스케일링)이 해당.
- 수정안: `max-height: calc(100vh - 78px - 16px); overflow-y: auto` 또는 900px 미만 높이에서 sticky 해제.

### B-1. [모바일] 서식 상세에서 다운로드 버튼까지 3화면 이상 스크롤
- 순서가 빵부스러기 → **미리보기 이미지(2페이지면 약 2,000px)** → 제목 → 다운로드. 폰 사용자는 제목도 못 보고 이미지부터 보며 "어디서 받지?"가 됨. 체류시간 목적이라도 다운로드 위치를 모르면 이탈.
- 수정안(택1): ① 모바일에서 순서를 제목 → 다운로드 3버튼 → 미리보기 → 나머지로 재배치(CSS `order`) ② 하단 고정 바 "PDF · Word · 한글"(광고 오클릭 방지 위해 광고와 분리) ③ 미리보기 첫 페이지만 보여주고 "2페이지 더 보기" 접기.

### B-4. [모바일] 계열 비교표(이력서 7종)가 오른쪽으로 잘려 Word·한글 버튼이 안 보임
- 표 폭 477px > 컨테이너 335px. `overflow-x: auto`라 밀면 보이지만 힌트가 없어 "PDF만 있나?"로 오해.
- 수정안: 모바일에서 표 대신 카드 리스트(버전명·한 줄 설명·3버튼)로 전환, 또는 오른쪽 그라데이션 + "옆으로 밀어 보세요" 안내.

### C-8. [공통] 미리보기 이미지 확대 불가
- 상세 미리보기가 `<img>`만 있고 클릭·확대 없음(cursor: auto). 폰에서는 글자가 안 읽힘. 탭하면 전체화면(핀치 줌 가능) 라이트박스 권장. PC 우측 다운로드 패널은 sticky가 아니라 2페이지 미리보기를 읽는 동안 버튼이 사라짐 → `position: sticky` 권장.

### C-9. [모바일] 분류 페이지 상단에 15개 분류 칩 블록이 먼저 나와 서식 목록이 한 화면 아래
- 현재 분류를 제목으로 보여주고 칩 블록은 "다른 분류 보기 ▾"로 접기, 또는 가로 스크롤 한 줄 칩으로.

### C-10. [모바일] 카드 다운로드 버튼 높이 33px (권장 터치 44px)
- PDF/Word/한글 버튼 42×33px. 손가락 오탭 → 옆 형식 다운로드. 높이 40px 이상 + 간격 8px 권장.

### C-11. [모바일] 푸터의 15개 분류 링크 세로 나열로 푸터가 2화면
- 접기 또는 대분류 7개만 노출. "맨 위로" 버튼 없음(상세 페이지는 5,000px 이상).

### C-12. [PC] 헤더 드롭다운이 hover 전용
- `:focus-within` 규칙 없음 → 키보드 Tab 사용자는 하위 분류를 못 열음(상위 링크가 첫 분류로 가긴 함). `li:hover, li:focus-within .submenu` 로 확장.

### C-13. [공통] "한글" 버튼이 HWPX임을 버튼 자체에서 알 수 없음
- 제공 형식 표에는 "한글(HWPX)"이라고 있으나 카드 버튼은 "한글"뿐. 한글 2010 이하 사용자는 열리지 않아 "파일이 깨졌다"고 느낄 수 있음. 버튼 툴팁/상세 다운로드 패널에 "HWPX · 한글 2014 이상" 한 줄.

### C-14. [공통] 상세 페이지 "이 서식이 들어 있는 모음"의 분류 어긋남 사례
- 표준근로계약서 → "취업 준비 서식" 모음에 연결. 근로계약서는 회사(인사담당) 문서라 "퇴사할 때/창업 첫 달"이 더 자연스러움. 모음 편성 재점검 권장(전수는 미확인).

| C | 버튼 터치 높이 33px | 오탭 가능 | 40px 이상 |

모바일에서 정상 확인: 계산기 입력칸 `inputmode="numeric"`(숫자 키패드) 적용, 입력 높이 46px, 카드 2열 그리드·간격 정상, 도장 프리셋 2열 정상, 요청 폼 글자수 카운터 정상, 가로 넘침 없음.
