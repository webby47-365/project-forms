## 1. C-1묶음 — 소형 마감 6건

### C-1. 모바일 티커 라벨과 흐르는 글자 겹침
- 현상: 375px에서 "최근 업데이트" 라벨 오른쪽 끝 93px, 흐르는 트랙 시작 102px → 항목 앞글자가 라벨에 붙어 잘려 보임.
- 요구: 720px 이하에서 ① 라벨 오른쪽 padding 12px 이상 ② 트랙 왼쪽 끝에 12px 페이드(`mask-image: linear-gradient(to right, transparent, #000 12px)` 또는 라벨 배경색 그라데이션 오버레이). 라벨과 트랙 사이 시각 간격 ≥ 12px.

### C-3. 푸터 도구 목록 구분자
- 현상: "직장인 도구 · 도장·서명 만들기 · 실수령액 계산기 …" — 항목 구분 `·` 와 이름 안의 `·` 가 같은 기호.
- 요구: 푸터의 도구 목록·사이트 링크 줄의 **항목 구분자를 `|`(연한 색, 좌우 8px)** 로 바꾼다. 이름 안의 `·` 는 그대로. `base.html` 푸터에서 도구 목록을 자동 나열하는 부분만 수정(카테고리 목록 "기업 · 인사·노무" 는 대분류·중분류 구분이라 유지).
- PC·모바일 공통 적용(글자 변경이므로 PC 변경 허용).

### C-12. PC 헤더 드롭다운 키보드 접근

- 요구: 같은 규칙에 `li:focus-within` 추가. 하위 링크 포커스 시 상위 a 배경도 hover와 같게. 시각 변화는 키보드 조작 때만 발생하므로 PC 픽셀 비교에는 영향 없음.
- 검증: Tab 키를 눌러 "기업"에 포커스 → 다음 Tab에서 "인사·노무"로 포커스가 들어가고 드롭다운이 보인다.

### C-4. 계산기 입력 검증 (3종 공통, `assets/calc.js` · `templates/tool_calc.html`)
- 현상: 연봉 칸에 문자("abc") → 조용히 0원, 음수("-5000") → "-5,000"이 남고 결과 0원. 안내 없음.
- 요구:
  - 숫자 외 문자는 입력 즉시 제거(현재 콤마 포맷 로직에 통합). 음수 기호는 받지 않는다.
  - 값이 비었거나 0이면 결과 영역 위에 한 줄 안내 "금액을 입력하면 바로 계산됩니다" (muted, 13px), 결과 숫자는 "—" 로 표시(0원 나열 대신).

## 3. C-3묶음 — 검색 오타 완화 (C-7)

### 현상
- "이렬서"·"차동차 이력서"처럼 한 글자 오타에 결과 0건. 현재는 부분 문자열 일치.

### 요구
- **색인**: `search-index.json` 생성부(build_site.py)에 각 서식의 검색 대상 문자열(제목·variant·태그·계열명)을 **2글자 조각(bigram)** 으로 만든 배열을 추가하거나, 클라이언트에서 즉석 생성(색인 크기가 부담되면 후자). 공백·괄호는 제거하고 자모 분해는 하지 않는다.
- **판정 순서** (위가 우선, 같은 등급 안에서는 기존 정렬 유지):
  1. 기존 부분 문자열 일치(현행 로직) — 결과 있으면 그대로 최상단.
  2. 없거나 3건 미만이면 bigram 겹침 비율 = 겹친 조각 수 ÷ 검색어 조각 수. **0.5 이상**이면 후보에 추가(상한 20건), 비율 내림차순.
  3. 검색어가 2글자 이하이면 bigram 단계 생략(오탐 방지).
- **화면 표시**: bigram로만 찾은 결과는 결과 제목 아래 안내 한 줄 "'이렬서'와 비슷한 서식을 찾았습니다" 를 붙이고, 0건 안내·요청 배너는 그대로 유지(비슷한 결과가 있어도 "그래도 없으면 요청하세요"는 남긴다).
- 헤더 자동완성(`#sresults`)에도 같은 규칙 적용(부분 일치 0건일 때만 bigram).
- 기존 정상 검색 결과가 바뀌지 않아야 한다: "사직서" 3종, "근로 계약서" 5종, "이력" 13종, "resume" 7종, "퇴직" 5종 — 순서까지 동일.

### 검증 기준
- "이렬서" → 이력서 계열 7종 이상 표시 + 안내문. "차동차 이력서" → 자동차 관리이력서 포함. "근로계악서" → 근로계약서 5종.
- 위 정상 검색 5개의 건수·순서 배포 전과 동일(먼저 라이브에서 기록).
- "zzzz"·"ㅁ" → 0건 안내 유지. 2글자 "이력" 은 bigram 미적용.
- 색인 파일 크기 증가율 보고(2배 초과면 클라이언트 생성 방식으로 전환).
- 캡처: 375 `/search/?q=이렬서`, 1366 헤더 자동완성 "이렬".
